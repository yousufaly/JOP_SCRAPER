# 🕵️ Job Scraper

## 📌 Description

A simple Python script that scrapes job listings from a demo website and saves them into a CSV file.

## 🌐 Website Used

https://realpython.github.io/fake-jobs/

## ⚙️ Requirements

- Python 3.x

Install dependencies:

```bash
pip install -r requirements.txt
python script.py
```
